# NEXA AI

Una plataforma inteligente para estudiar, crear y trabajar.

> Proyecto en desarrollo activo. Estado actual: **Fase 1 — Base del proyecto**. Ver [`PLAN.md`](./PLAN.md) para el detalle completo de fases y arquitectura.

## Stack

Next.js (App Router) · TypeScript · Tailwind CSS · shadcn/ui · Supabase (Auth, PostgreSQL, Storage) · Gemini API / Groq (capa de IA intercambiable)

## Desarrollo

```bash
npm install
npm run dev
```

Abre [http://localhost:3000](http://localhost:3000).

Ver [`docs/DEVELOPMENT.md`](./docs/DEVELOPMENT.md) para el flujo de trabajo completo por fase.
